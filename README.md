# Soak It

A game by Taha.

You are holding a fire hose. Swing it with your left thumb, set the water
pressure with your right, and put every fire out before it spreads. Your
time is your score.

**Play it here:** https://taha-makes-stuff.github.io/soak-it/

`index.html` is the whole game in one file. `version.json` tells the Android
app when a new version has been published, so it can update itself without
anyone reinstalling anything.
